<Update label="Março de 2026" description="v1.9.0">

### Personalização de campanhas com listas de contatos

As campanhas agora suportam variáveis vindas da lista de contatos, para você personalizar cada mensagem com dados mais ricos de cada inscrito.

### Personalização do double opt-in

O double opt-in agora permite personalizar o fluxo e os textos de confirmação, ficando mais fácil alinhar a experiência de boas-vindas e os requisitos de conformidade.

### Cobertura na API e nos SDKs

O suporte a listas de contatos foi ampliado no SDK, as análises do dashboard passaram a estar disponíveis na API pública e no SDK, e foi adicionado um endpoint público para excluir campanhas.

### Filtro de webhooks por domínio

Os webhooks agora suportam filtro por múltiplos domínios, facilitando o roteamento, o monitoramento e a gestão de eventos entre projetos diferentes.

</Update>

### Webhooks

Agora você pode receber notificações em tempo real de eventos de e-mail via webhooks. Configure endpoints de webhook para acompanhar entregas, bounces, reclamações e mais. [Saiba mais](https://docs.madmail.com.br/guides/webhooks)

### API de listas de contatos

Gerencie suas listas de contatos de forma programática com a nova API pública. Crie, atualize e organize contatos em escala.

### Suporte a idempotência

As requisições da API agora aceitam chaves de idempotência, garantindo retentativas seguras sem envios duplicados.

### Outras melhorias

- Exporte listas de contatos em CSV para uso offline.
- Correções de segurança para as CVE-2025-55184 e CVE-2025-55183.
- Diversas correções de bugs e melhorias de performance.

</Update>

### Agendamento de campanhas

Agora você pode agendar campanhas usando linguagem natural, como "amanhã às 9h" ou "próxima segunda às 10h".

### API de campanhas

Estamos investindo cada vez mais nas APIs. Agora você pode criar e agendar e-mails de campanha pela API. Confira a [documentação da API](/api-reference/introduction)

### Outras melhorias

- Os e-mails de campanha agora são enviados em lotes, em vez de uma rajada única.
- Você pode importar grandes volumes de contatos sem lentidão na interface.
- Adicionada a API de exclusão de domínio.

</Update>

Endereços com hard bounce ou que marcaram o e-mail como spam são adicionados automaticamente à lista de supressão. Vale tanto para e-mails transacionais quanto de marketing.
