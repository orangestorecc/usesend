## Visão geral

O double opt-in exige que novos contatos confirmem o endereço de e-mail antes de ficarem inscritos. Quando ativado em uma lista de contatos, todo contato recém-adicionado recebe um e-mail de confirmação com um link de verificação. Só depois de clicar no link ele passa a ficar totalmente inscrito.

**Por que usar double opt-in?**

- Garante que os endereços de e-mail são válidos e pertencem ao inscrito
- Reduz taxas de bounce e reclamações de spam
- Melhora a entregabilidade e a reputação do remetente
- Ajuda na conformidade com regulamentações de e-mail marketing (LGPD, GDPR, CAN-SPAM)

## Como funciona

<Steps>
  <Step title="O contato é adicionado">
    Quando um contato é adicionado a uma lista com double opt-in ativado (pelo
    dashboard, pela API ou por importação de CSV), ele é criado com o status
    **Pendente**, em vez de ser inscrito imediatamente.
  </Step>
  <Step title="O e-mail de confirmação é enviado">
    Um e-mail de confirmação é enviado automaticamente ao contato com um link de
    verificação único. O link é assinado com HMAC-SHA256 e expira em 7 dias.
  </Step>
  <Step title="O contato confirma">
    O contato clica no link de verificação do e-mail e confirma a inscrição na
    página de confirmação.
  </Step>
  <Step title="O contato fica inscrito">
    O status do contato muda de **Pendente** para **Inscrito** e ele passa a
    receber seus e-mails.
  </Step>
</Steps>

## Ativando o double opt-in

### Pelo dashboard

1. Acesse [Contatos](https://app.madmail.com.br/contacts) e selecione uma lista de contatos
2. Clique na aba **Double Opt-In**
3. Ative o double opt-in
4. Personalize o e-mail de confirmação (opcional)
5. Salve as alterações

### Pela API

Crie uma lista de contatos com double opt-in ativado:

```bash
curl -X POST https://app.madmail.com.br/api/v1/contactBooks \
  -H "Authorization: Bearer us_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Newsletter Subscribers",
    "doubleOptInEnabled": true,
    "doubleOptInFrom": "Newsletter <hello@yourdomain.com>",
    "doubleOptInSubject": "Please confirm your subscription"
  }'
```

Ou ative em uma lista já existente:

```bash
curl -X PATCH https://app.madmail.com.br/api/v1/contactBooks/{contactBookId} \
  -H "Authorization: Bearer us_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "doubleOptInEnabled": true
  }'
```

## Status dos contatos

Com o double opt-in ativado, os contatos podem ter três status:

| Status           | Descrição                                                        |
| ---------------- | ---------------------------------------------------------------- |
| **Inscrito**     | O contato confirmou a inscrição e vai receber e-mails            |
| **Pendente**     | O contato foi adicionado, mas ainda não confirmou                |
| **Descadastrado**| O contato cancelou a inscrição explicitamente                    |

<Warning>
  Contatos com status **Pendente** não recebem e-mails de campanha. Eles só
  recebem o e-mail de confirmação do double opt-in.
</Warning>

## Personalizando o e-mail de confirmação

Você pode personalizar três aspectos do e-mail de confirmação:

### Endereço de remetente

Defina um remetente personalizado para os e-mails de confirmação. O endereço precisa usar um dos seus domínios verificados.

```json
{
  "doubleOptInFrom": "Newsletter <hello@yourdomain.com>"
}
```

Se não for definido, o e-mail de confirmação será enviado pelo primeiro domínio verificado disponível.

### Assunto

Personalize o assunto do e-mail. O padrão é "Please confirm your subscription".

```json
{
  "doubleOptInSubject": "Confirm your subscription to our newsletter"
}
```

### Template do e-mail

O corpo do e-mail de confirmação pode ser personalizado no editor de e-mails do Madmail (pelo dashboard) ou enviando o conteúdo JSON do editor pela API.

#### Variáveis do template

As variáveis a seguir podem ser usadas no template do e-mail de confirmação:

| Variável             | Descrição                            |
| -------------------- | ------------------------------------ |
| `{{doubleOptInUrl}}` | O link de confirmação (obrigatório)  |
| `{{email}}`          | O e-mail do contato                  |
| `{{firstName}}`      | O primeiro nome do contato           |
| `{{lastName}}`       | O sobrenome do contato               |

<Warning>
  A variável `{{ doubleOptInUrl }}` é **obrigatória** no template do e-mail. O
  e-mail de confirmação não pode ser salvo sem ela. Isso garante que todo e-mail
  de confirmação contenha um link de verificação funcional.
</Warning>

## Reenviando e-mails de confirmação

Se um contato ainda não confirmou a inscrição, você pode reenviar o e-mail de confirmação pelo dashboard:

1. Abra sua lista de contatos e localize o contato pendente
2. Clique no botão **Reenviar** ao lado do contato

Cada reenvio gera um novo link de confirmação, com uma nova janela de validade de 7 dias.

## Boas práticas

| Boa prática                            | Por que ajuda                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------ |
| Configure um domínio verificado antes  | Os e-mails de double opt-in precisam de um domínio verificado para serem enviados    |
| Mantenha o e-mail de confirmação simples | Facilita para o inscrito entender e concluir a etapa de confirmação                 |
| Use um remetente reconhecível          | Reduz a chance de o e-mail de confirmação ser ignorado ou marcado como spam          |
| Acompanhe os contatos pendentes        | Ajuda a identificar taxas baixas de confirmação e melhorar seu fluxo de cadastro     |
