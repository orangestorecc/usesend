## URL base

A API do Madmail segue os princípios REST e é servida por HTTPS. Para garantir a
privacidade dos dados, HTTP sem criptografia não é suportado.

A URL base de todos os endpoints é:

```sh Terminal
https://app.madmail.com.br/api/
```

## Autenticação

A autenticação na API do Madmail é feita pelo cabeçalho `Authorization` com um
token Bearer. Inclua o cabeçalho com a palavra `Bearer` seguida do seu token:

```sh Terminal
Authorization: Bearer us_12345
```

Você cria um token/chave de API nas
[Configurações de desenvolvedor](https://app.madmail.com.br/dev-settings/api-keys)
do Madmail.

## Conector de IA (MCP)

Além da API REST, o Madmail expõe um servidor **MCP** (Model Context Protocol) —
o padrão aberto que permite que assistentes como o **ChatGPT** e o **Claude**
usem ferramentas externas. É assim que você **dispara conversando**: você
descreve a campanha, o assistente executa no Madmail.

<Info>
  Você não precisa escrever código para usar o MCP. Basta conectar o seu
  assistente ao endereço abaixo e autorizar o acesso à sua conta.
</Info>

### Endpoint

```sh Terminal
https://mcp.madmail.com.br/mcp
```

A autorização é feita por **OAuth**: ao conectar, o assistente abre a tela de
login do Madmail e você aprova o acesso. Nenhuma chave é copiada manualmente, e
você pode revogar o acesso quando quiser em
[Configurações de desenvolvedor](https://app.madmail.com.br/dev-settings/mcp).
