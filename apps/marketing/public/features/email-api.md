# Email API — Madmail

> Dispare e-mails transacionais (confirmações, senha, avisos de pedido) com uma
> API REST simples, com entregabilidade e métricas cuidadas.

## Destaques

- Endpoints REST diretos, sem SDK obrigatório.
- SPF, DKIM e DMARC já configurados.
- Webhooks de entrega, abertura, clique e queda.

## Detalhes

- **Integração em minutos**: gere uma chave e faça a primeira chamada; docs com
  exemplos prontos em várias linguagens.
- **Confiável no volume**: retentativas, supressão automática e log pesquisável
  de cada envio, na mesma infraestrutura das campanhas.
